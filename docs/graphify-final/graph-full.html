How to use this viewer

This is a full graph browser, not a static picture. Search any node, file, repository, function, class, or concept. Select it to see connected nodes and the exact relationship label, source file, source line, and confidence.

The source data remains complete in graph.json. This viewer displays the complete data progressively so your browser does not attempt to draw 140,000 nodes and 350,000 edges simultaneously.
